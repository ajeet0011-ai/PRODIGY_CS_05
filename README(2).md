# Packet Sniffer Tool

Educational packet sniffer built with Python and Scapy.

## Features

- Capture live network packets
- Display source and destination IP addresses
- Detect TCP and UDP protocols
- Show port information
- Preview packet payloads

## Installation

```bash
pip install -r requirements.txt
```

## Run

Linux/macOS:

```bash
sudo python main.py
```

Windows (Run terminal as Administrator):

```bash
python main.py
```

## Requirements

- Python 3.8+
- Scapy
